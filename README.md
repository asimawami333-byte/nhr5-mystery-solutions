# NHR5 — The Ultimate Mystery Challenge

Official companion repository for **The Ultimate Mystery Challenge: 100 Extreme Mystery Puzzles**.

## Live answer website
https://asimawami333-byte.github.io/nhr5-mystery-solutions/

## Project files
- `index.html` — responsive black-and-gold answer website with search and category filters.
- `puzzles.js` — all 100 cases, answers, and explanations used by the website.
- `book-manuscript.md` — answer-free manuscript containing all 100 puzzles and the final solutions-page copy.

## Puzzle structure
There are 100 cases across five categories, with 20 cases in each:
1. Locked-Room Mysteries
2. Criminal Deduction
3. Hidden Evidence
4. Secret Codes & Messages
5. Master Detective Cases

The printed book intentionally excludes the answers. Readers use the live website to reveal solutions.
