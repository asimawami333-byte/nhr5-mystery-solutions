WELCOME, DETECTIVE

ONE HUNDRED CASES. ONE HUNDRED CHANCES TO THINK.

Read every clue carefully. Question every assumption. Write down your conclusion before moving to the next case.

The five sections test deduction, observation, codes, and careful interpretation. Some cases ask you to recognize when evidence is insufficient or when the stated conditions cannot all be true.

Answers and explanations are intentionally excluded from this printed book. They are available on the official NHR5 companion website. The final page contains a QR code and the website address.

HOW TO USE THIS BOOK

YOUR INVESTIGATION

  1. Read the full scenario before answering.
  2. Separate facts from assumptions.
  3. Check whether every clue can be true at the same time.
  4. If the evidence does not identify one answer, say so.
  5. When you finish, use the companion website to reveal the official answer and explanation.

There is no need to rush. Accuracy matters more than speed.
